## Retained differences and remaining work

- **Temporary presentation adapter:** the main page reuses Chimera's existing table and detail row, turning a persisted `ClosedConnection` into a `ConnectionRow` for display. The toolbar, status tabs and route filters now follow the reference decomposition, but the reference uses `AnyConnectionRow`, separate `ActiveViewer`, `AllViewer`, and `ClosedViewer` modules, plus shared cell and row-selection helpers. Continue migration by restoring those corresponding modules and remove `closedConnectionRow` only when the shared table renders each row kind directly.
- **Geo lookup compatibility gap:** destination region labels and lookup basis are derived from Geo fields already supplied in the Clash connection snapshot. Chimera has no matching local GeoIP index or local/public source IP probe in this path; local source region therefore remains `unknown`, and destination region is unknown when the core supplies no Geo label. Do not claim full geo-dimension parity until that adapter and its configuration are migrated and tested.
- **Shared UI and cross-navigation gaps:** Chimera does not yet have ref's shared `SegmentedButton` primitive or Connections `ReturnButton` / cross-navigation module. StatusTabs currently uses the same Radix single-value group semantics without the ref slider/ripple, and row details do not yet offer the ref's locate-rule and view-rule-usage return flow. Port these shared navigation/UI boundaries before calling the presentation fully aligned.
- **Legacy UI:** the existing legacy Connections page remains active-only and retains its table/detail interactions. It continues using the same Clash connection API; the new closed-history presentation is currently main-UI only, matching the reference feature's main route. No legacy UI or route was removed.
- **Agent:** there is no reference Connections agent entry point to map. The agent continues to access only its existing tools; exposing traffic history to it is a separate extension task.
- **Runtime coverage:** unit and actor integration tests exercise the traffic store and lifecycle. A desktop spec covers tab/range/filter route state. No real-core network recording, app restart persistence, cross-core matrix, source GeoIP lookup, or filtered-row desktop assertion has been run in this slice.

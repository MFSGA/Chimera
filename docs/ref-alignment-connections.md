## Retained differences and remaining work

- **Native detail stream aligned, browser SSE still pending:** `useActiveConnectionRows` now consumes `ClashConnectionDetailsProvider` frames derived from typed `chimera_clash_api::Connection`, with per-connection bytes/sec based on actual elapsed time. The shared Clash actor publishes the latest full details only while native Channel subscribers exist. The adapter tracks subscriptions per webview, validates owners, and cancels on unsubscribe, page reload and destruction. These operations are independent of the historic Connections recording toggle. Unlike ref, Chimera does not yet expose the UnifiedRpc HTTP SSE `/bridge/connection-details` path; ordinary browser-only runs cannot consume this stream, and have an explicit unavailable state instead of a fabricated data source. Full parity also requires validating the native Channel and web bridge in desktop/browser integration tests.
- **Geo lookup compatibility gap:** destination region labels and lookup basis are derived from Geo fields already supplied in the Clash connection snapshot. Chimera has no matching local GeoIP index or local/public source IP probe in this path; local source region therefore remains `unknown`, and destination region is unknown when the core supplies no Geo label. Do not claim full geo-dimension parity until that adapter and its configuration are migrated and tested.
- **Shared UI and cross-navigation boundaries:** `SegmentedButton` (slider/ripple), `ReturnButton`, cross-navigation ticket utilities and focus highlight styling are now ported; Main Connections locates rules with return focus, and Legacy routes to its rule filter. The reference's `View Rule Usage` link targets `/main/topology`, which Chimera does not currently provide. Do not enable a broken link or claim that navigation is complete without that route and its shared traffic view.
- **Legacy UI (2026-10-09):** `frontend/chimera/src/pages/(legacy)/connections.tsx` now mounts the same `ConnectionsContent` component as Main, replacing the prior legacy-only active table on this page. The retained `BasePage` header and a scoped `connections.scss` adapter provide the Legacy window layout while the table retains a separate scrolling viewport. Legacy now presents the shared Active/All/Closed tabs, search, filters, column settings, virtual table, detail modal and close actions. Main still owns URL-backed selection, while Legacy keeps presentation-only selection locally; both use the same shared Clash/traffic APIs. The old legacy-only components have been left in place pending desktop regression validation, not duplicated as a second live connection business implementation.
- **Agent:** there is no reference Connections agent entry point to map. The agent continues to access only its existing tools; exposing traffic history to it is a separate extension task.
- **Runtime coverage:** unit and actor integration tests exercise the traffic store and lifecycle. A desktop spec covers tab/range/filter route state. No real-core network recording, app restart persistence, cross-core matrix, source GeoIP lookup, or filtered-row desktop assertion has been run in this slice.

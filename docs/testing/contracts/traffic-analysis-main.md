# Contract TRAFFIC-URL-STATE — main traffic analysis route

| Field                         | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Risk                          | L2: the UI route is read-only, but `useTrafficReport` is shared with filtered Connections statistics and this batch changes its pause, focus/reconnect and retry policy. No runtime configuration, system proxy, TUN, or persistent data mutation.                                                                                                                                                                                                                             |
| Boundary                      | Desktop UI E2E for the actual main window; a separate unit suite covers pure URL-to-query mapping.                                                                                                                                                                                                                                                                                                                                                                             |
| Base suite                    | `main`; included by the PR `hermetic` suite.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Initial state                 | The main window is selected and resized to 1280 × 720, then placed on `/main/dashboard` through the visible navbar if needed. It does not require a profile or live core data, and assertions use stable selectors rather than localized text.                                                                                                                                                                                                                                 |
| Operation                     | Click the visible Traffic item in the main navbar, select Closed scope, focus the metric trigger and use Enter/ArrowDown/Enter to select Connections, then open Flow and Geography from the traffic sidebar. Toggle the sidebar open and closed.                                                                                                                                                                                                                               |
| Expected result               | The Traffic page mounts, the scope and metric controls update the URL, then Flow and Geography become active in the sidebar while `scope=closed` and `metric=connections` remain in the URL. The sidebar toggle exposes a non-empty label that changes with `aria-expanded` and returns to its collapsed label. This catches missing route registration, controls that do not update router state, and child navigation that drops the query.                                  |
| Independent result source     | Browser location and the active sidebar link are read after each user-control action. The test does not infer router state from React internals. If the report query fails, the page may show its unavailable notice instead of route-specific data; the test intentionally does not require a child data-view marker.                                                                                                                                                         |
| Real dependencies             | Bundled Chimera frontend, Tauri main window and existing traffic-report IPC hook. The backend report may be empty or unavailable; neither is the behavior under test.                                                                                                                                                                                                                                                                                                          |
| Mock or bypass                | No application mock and no direct IPC call. `ensureMainWindow` and a dashboard navigation only prepare the starting route; the measured actions use WebDriver element clicks plus keyboard activation after programmatic focus. This does not cover Tab order or native pointer-event behavior.                                                                                                                                                                                |
| Failure path                  | A failed report query remains visible as an unavailable notice; this route-state test should still exercise the controls. It does not claim to test query error recovery or runtime traffic collection.                                                                                                                                                                                                                                                                        |
| Omitted coverage              | The desktop route test does not induce window focus or network reconnect to assert the pause policy. The runnable traffic unit suite verifies transient command-error recovery for a no-poll caller and that paused query options set focus/reconnect/retry to false. The Connections detail “view rule usage” cross-navigation is not clicked because this case has no seeded live connection row. Cover those behaviors in focused tests when the harness has safe fixtures. |
| Network and host effects      | No direct IP probe, external map request, host networking mutation, or TUN/service operation. The map uses the bundled Natural Earth asset and only region values already present in the backend report.                                                                                                                                                                                                                                                                       |
| Persistence/restart           | Not applicable: search state is URL state, not a persisted setting. No reload or cold-start claim.                                                                                                                                                                                                                                                                                                                                                                             |
| Diagnostics and cleanup       | Test-owned route/window only. Failures retain the WDIO assertion/timeout and suite diagnostics; no user profile or host setting is changed. Two earlier local runs (`v6`, `v7`) timed out in WebDriver `execute/async`; a fresh isolated rerun on the same binary passed once. Treat the timeout as intermittent and unresolved until the new SHA's CI result or repeated local evidence confirms stability.                                                                   |
| Unit counterpart              | `pnpm --filter=chimera-ui test:traffic` proves default search values, query/topology request mappings, transient query retry, and pause options; it does not prove desktop behavior.                                                                                                                                                                                                                                                                                           |
| Reference mapping             | `ref/frontend/nyanpasu/src/pages/(main)/main/topology/` → `frontend/chimera/src/pages/(main)/main/topology/`; query schema and control semantics retained. Chimera's existing `Sidebar`, `useTrafficReport`, connection filters and cross-navigation are the adapters.                                                                                                                                                                                                         |
| Deliberate partial difference | Upstream local-IP probing and its opt-in/geolocation index are not ported. The map displays unknown local source regions rather than probing a public IP service. Revisit only with an explicit opt-in, TUN exclusion, and dedicated privacy-safe tests.                                                                                                                                                                                                                       |

# Contract TRAFFIC-URL-STATE — main traffic analysis route

| Field                         | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Risk                          | L2: the UI route is read-only, but `useTrafficReport` is shared with filtered Connections statistics and this batch changes its pause, focus/reconnect and retry policy. No runtime configuration, system proxy, TUN, or persistent data mutation.                                                                                                                                                                                                                                                                                                           |
| Boundary                      | Desktop UI E2E for the actual main window; frontend unit tests cover URL-to-query mapping, and backend Rust unit/actor tests cover local GeoIP loading and traffic-frame mapping. This route spec does not exercise a running core database.                                                                                                                                                                                                                                                                                                                 |
| Base suite                    | `main`; included by the PR `hermetic` suite.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Initial state                 | The main window is selected and resized to 1280 × 720, then placed on `/main/dashboard` through the visible navbar if needed. The test waits for any exiting traffic page from the previous route transition to leave the DOM before opening Traffic, so it cannot target a stale sidebar. It does not require a profile or live core data, and assertions use stable selectors rather than localized text.                                                                                                                                                  |
| Operation                     | Click the visible Traffic item in the main navbar, establish and assert the All scope as the precondition, select Closed scope, focus the metric trigger and use Enter/ArrowDown/Enter to select Connections, then open Flow and Geography from the traffic sidebar. Toggle the sidebar open and closed.                                                                                                                                                                                                                                                     |
| Expected result               | The Traffic page mounts, the test observes `scope=all` with All checked before clicking Closed, then observes `scope=closed` with Closed checked. The metric control updates the URL, then Flow and Geography become active in the sidebar while `scope=closed` and `metric=connections` remain in the URL. The sidebar toggle exposes a non-empty label that changes with `aria-expanded` and returns to its collapsed label. This catches missing route registration, controls that do not update router state, and child navigation that drops the query. |
| Independent result source     | Browser location and the active sidebar link are read after each user-control action. The test does not infer router state from React internals. If the report query fails, the page may show its unavailable notice instead of route-specific data; the test intentionally does not require a child data-view marker.                                                                                                                                                                                                                                       |
| Real dependencies             | Bundled Chimera frontend, Tauri main window and existing traffic-report IPC hook. The backend report may be empty or unavailable; neither is the behavior under test.                                                                                                                                                                                                                                                                                                                                                                                        |
| Mock or bypass                | No application mock and no direct IPC call. `ensureMainWindow` and a dashboard navigation only prepare the starting route; the measured actions use WebDriver element clicks plus keyboard activation after programmatic focus. This does not cover Tab order or native pointer-event behavior.                                                                                                                                                                                                                                                              |
| Failure path                  | A failed report query remains visible as an unavailable notice; this route-state test should still exercise the controls. It does not claim to test query error recovery or runtime traffic collection.                                                                                                                                                                                                                                                                                                                                                      |
| Omitted coverage              | The desktop route test does not induce window focus or network reconnect to assert the pause policy. The runnable traffic unit suite verifies transient command-error recovery for a no-poll caller and that paused query options set focus/reconnect/retry to false. The Connections detail “view rule usage” cross-navigation is not clicked because this case has no seeded live connection row. Cover those behaviors in focused tests when the harness has safe fixtures.                                                                               |
| Network and host effects      | No public-IP probe, external map request, host networking mutation, or TUN operation. The backend reads the core local GeoIP database and reads `/configs` through the active core controller using proxy bypass; the configured controller address can be non-loopback. The map uses the bundled Natural Earth asset. Unit tests use in-memory country fixtures and make no network requests.                                                                                                                                                               |
| Persistence/restart           | Not applicable: search state is URL state, not a persisted setting. No reload or cold-start claim.                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Diagnostics and cleanup       | Test-owned route/window only. Failures retain the WDIO assertion/timeout and suite diagnostics; no user profile or host setting is changed. Two earlier local runs (`v6`, `v7`) timed out in WebDriver `execute/async`; the isolated macOS rerun passed, and the corrected route/menu flow passed on the exact current PR SHA in Windows Edge. The historical local timeout remains documented but does not block this verified PR result.                                                                                                                   |
| Unit counterpart              | `pnpm --filter=chimera-ui test:traffic` proves URL/query behavior, retry, and pause options. `cargo test --manifest-path backend/Cargo.toml -p chimera --lib core::geo::` and `cargo test --manifest-path backend/Cargo.toml -p chimera --lib core::traffic::` cover the local index actor, address selection, and frame mapping; none proves a real core or desktop session.                                                                                                                                                                                |
| Reference mapping             | `ref/frontend/nyanpasu/src/pages/(main)/main/topology/` → `frontend/chimera/src/pages/(main)/main/topology/`; query schema and control semantics retained. `ref/backend/nyanpasu-geodata/` and `ref/backend/tauri/src/core/geo/` → `backend/chimera-geodata/` and `backend/tauri/src/core/geo/`; `ref/backend/tauri/src/core/traffic/geo.rs` → the same Chimera path. Main, Legacy, and agent continue to share the existing traffic application API.                                                                                                        |
| Deliberate partial difference | The local GeoIP index is ported, but ref's local-source public-IP probe and opt-in setting remain omitted. Local and private source regions stay unknown because Chimera supplies no externally probed address. Revisit only with explicit opt-in, TUN exclusion, and privacy-safe tests.                                                                                                                                                                                                                                                                    |

Earlier logs show WebDriver `execute/async` timeouts followed by the
`scrollIntoView` fallback; those timeouts alone do not establish the final test
result. The shared `afterTest` hook had read the Mocha context instead of its
third-argument result, causing successful runs to produce failure artifacts.
After correcting that signature, the isolated macOS WebKit run passed 1/1 with
no failure artifacts. Windows Desktop E2E run
[39018118841](https://github.com/MFSGA/Chimera/actions/runs/39018118841) passed
on head `c50d0e68c44b558c2cb5b97dfdd6e43ecf253018`. Independent review then
found the Closed-scope assertion lacked a guaranteed pre-state; the follow-up
now establishes and asserts All before clicking Closed. The exact updated PR
head `13699341fc9389b4c18369609618e2fc944dddc3` passed Windows Desktop E2E run
[39037138976](https://github.com/MFSGA/Chimera/actions/runs/39037138976), 53/53
specs; the isolated Profile auto-update and controller fallback specs also
passed 1/1 each.

The toggle's changing ARIA attributes are read from the current DOM after each
transition, rather than from a WebDriver element handle retained across
rerenders. If a transition times out, the failure includes the final observed
toggle state.

# 测试契约与交付模板

与[规范](README.md)一起使用。短契约放在 spec 顶部注释，较复杂场景放在 `docs/testing/contracts/` 下并从 spec 链接；该目录可在首次使用时创建。一个文件可容纳多个独立契约，但每个行为必须有自己的预期和失败条件。所有尖括号内容均需填写，不能把模板占位符留作合规证据。

## 编写前填写

```text
契约 ID：<稳定 ID，例如 runtime-ipv6-sync>
用例标题：<触发条件 + 操作 + 可观察结果>
风险/回归：<具体错误实现，例如内核已更新但事件没有通知当前页面>
边界：<单元 / 集成 / 桌面 UI E2E / 网络 E2E / 系统验证>
基础套件：<已有分组；说明 PR 是否实际执行>
运行条件：<平台、provider、内核、窗口/路由、语言、网络前置条件>
真实依赖：<实际经过的 UI、IPC、文件、内核、网络>
模拟与绕过：<准备数据使用的 IPC/mock，以及因此未覆盖的部分；没有则写无>
初始状态：<如何准备、如何核验，不依赖其他 it>
被测操作：<真实入口；操作不放进轮询>
权威结果：<预期目标值/UID/token，以及独立读取来源>
当前 UI 结果：<不刷新时应出现的结果；不适用则说明>
磁盘/刷新/冷启动：<分别列出要求，不相互冒充>
失败或边界场景：<选择依据、注入位置、错误反馈及旧状态不变量>
等待预算：<每阶段期限、每次请求期限、观察间隔、诊断与清理余量>
诊断：<最后实际值、错误、截图/日志的唯一保存位置、脱敏方式>
资源与清理：<所有者、部分创建失败的处理、恢复顺序、残留验证>
回归敏感性：<旧实现或故障注入会在哪个断言失败>
相关规则与例外：<T01–T14；不适用项写原因>
```

## 设计示例：IPv6 当前页面同步

此例是**目标契约示例，不声称现有 IPv6 spec 已全部满足**。

- 边界：桌面 UI → IPC → 后端 → 内核配置；不声称验证真实 IPv6 数据包或原生鼠标事件。
- 初始状态：读取内核 ipv6 值并确认已挂载页面显示相同值；数据处于本轮测试目录。
- 操作：从页面控制项切换到相反值一次。
- 观察：有期限地读取内核配置与当前页面状态，二者均变为目标值；期间不刷新、不补写 IPC。
- 回归：若通知事件丢失，UI 一直保留原值，应在同步断言失败，不能刷新后通过。
- 扩展：若本次还改了持久化，另加磁盘或应用冷启动契约；页面 refresh 仅验证页面重新读取。
- 清理：恢复原值并核验；主体失败与恢复失败一起保留。

## 编码时的结构要求

以下为流程示意，**不是可直接导入的 helper 或已实现 API**；具体实现需按真实 UI、配置类型和 provider 适配。

```text
登记本次运行标识、诊断位置和清理任务
try
  准备最小数据；每创建一个资源立即登记清理
  验证窗口、路由、初始业务状态
  从契约指定入口执行一次业务操作
  只读等待权威结果与当前 UI 达到预期
  按契约追加文件、页面重载、冷启动或网络验证
catch 主体错误
  保存原始错误
  有期限地采集现场；采集失败另行记录
finally
  按依赖顺序执行全部清理；逐个收集错误
  验证本测试资源和宿主设置的恢复结果
若存在主体/清理错误：抛出原始错误或包含全部错误的 AggregateError
```

异步 helper 应保持单一职责，尽量小于 50 行，简要注释执行顺序。观察 helper 不应带“必要时刷新/重试点击/改配置”的隐藏副作用；异常不应默认转换成空集合或 false。

## 依赖限制例外记录

```text
例外 ID / 关联契约：<ID>
涉及规则：<例如 T03>
锁定版本及平台：<实际版本，不写 latest>
最小复现和上游证据：<代码/报告/固定版本源码位置>
限制：<具体缺失行为>
替代验证：<例如通过键盘激活后检查菜单布局>
明确未覆盖：<例如真实鼠标 pointerdown 激活>
责任人或跟踪任务：<可追溯记录>
解除条件：<哪个最小复现在何种驱动/版本通过后移除例外>
```

## 交付时填写

```text
实现/契约：<链接及适用规则>
构建身份：<提交或工作树标识、二进制路径/哈希、构建特性、内核版本>
环境：<Node、pnpm、OS、WebView、provider 和依赖版本>
静态/框架检查：<准确命令与退出结果>
桌面执行：<准确 spec/套件、通过/失败/跳过数量>
回归验证：<旧实现或等价反例在目标断言失败的证据>
重试/意外重启：<首次结果、重复结果及异常；没有则写无>
证据与清理：<产物位置、恢复结果、残留问题>
未执行/未覆盖：<原因与影响，不以静态通过代替>
规范例外：<记录链接；没有则写无>
```

只修改文档时，构建、桌面、回归等字段可标记为“不适用：未修改可执行代码”，并报告文档格式与链接检查。不要为了填写模板启动无关的桌面测试或修改宿主代理。
